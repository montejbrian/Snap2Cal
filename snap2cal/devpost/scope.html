Snap2Cal

Screenshot in → structured event out → instant .ics download.

⚡ The Unique Kernel

Instant event parsing with transparent, human-in-the-loop validation: dropping an image initiates an immediate shimmering placeholder, followed by high-contrast editable inputs that explicitly highlight missing or ambiguous fields (in amber) for quick human completion rather than silent AI hallucination.

🎯 Scope Boundaries

  • Single-Page Web App (SPA): Clean, responsive desktop/mobile-friendly UI.
  • Drag-and-Drop Zone: Supports standard image formats (PNG, JPG, WEBP).
  • Skeleton Shimmer Loader: Instant visual feedback during parsing.
  • Structured Field Extraction: Event Title, Date, Start Time, End Time, Location, Description.
  • High-Contrast Editable Card: Direct input editing with amber warnings for missing fields.
  • RFC 5545 .ics Export: Universal calendar export ready to open in any calendar client.
  • Multi-event images: Extracting multi-day conferences or multiple dates from one flyer.
  • Direct OAuth Sync: Google Calendar API or Microsoft Graph direct pushes.
  • Timezone Geocoding: Auto-resolving timezone offsets from physical city names.
  • Browser Extension: Right-click image directly to Snap2Cal.
  • No User Accounts / Auth: Zero sign-up overhead; pure instant client utility.
  • No Database / Server Storage: Ephemeral session; protects user privacy and reduces attack surface.
  • No Recurring Events: Only single-instance events supported in POC.
  • No Mobile App Store Build: Web application only.
